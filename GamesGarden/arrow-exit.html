Arrow Exit

Tap an arrow to send it flying. If the path off the board is clear, it escapes. Clear every arrow to win.

← Back to Games
How to play
• Tap any arrow — it slides in the direction it points.
• Clear path to the edge → it exits (green flash).
• Blocked by another arrow → it stays and you lose a heart (red flash).
• Order matters: a blocked arrow may free up after a few moves.
• Pinch or use + / − to zoom, drag to pan on busy boards.
