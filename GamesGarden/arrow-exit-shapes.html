Arrow ExitShapes

Tap an arrow to send it flying. If its path off the board is clear, it escapes. Every level is a different shape — and an arrow is away the moment it leaves the outline.

← Back to Games
How to play
• Tap any arrow — it slides in the direction it points.
• Clear path to the edge → it exits (green flash).
• Blocked by another arrow → it stays and you lose a heart (red flash).
• Order matters: a blocked arrow may free up after a few moves.
• The board changes shape every level — 36 of them, from diamonds to Tower Bridge.
• Pinch or use + / − to zoom, drag to pan on busy boards.
